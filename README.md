# Suchi Abhiruta — Portfolio

A professional portfolio website built with React + Vite.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Before publishing

1. The supplied resume is already included at `public/Suchi_Abhiruta_Resume.pdf`.
2. LinkedIn and email have already been added.
3. Update project details or add screenshots as needed.

## Deploy

This project can be deployed using GitHub Pages or Vercel.
